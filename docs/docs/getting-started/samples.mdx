# Samples

The package includes samples. Import them from the **Samples** tab of YAUI in the Package Manager.

| Sample | Contents |
|---|---|
| **Basic** | A panel with text and a button that uses the EventSystem. The button is a plain `YauiElement` with a script that changes its color and scale on pointer events. |
| **Controls** | Buttons, toggles, a toggle group, a slider, an input field, a dropdown and a scroll view. |
| **Custom Shader** | A custom material for elements, built on `Yaui.hlsl`. See [Custom Shaders](../manual/custom-shaders.mdx). |
